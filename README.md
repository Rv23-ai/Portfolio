# Personal Portfolio Website

An interactive personal portfolio built with Next.js (App Router), featuring project case studies and an embedded serverless AI chat assistant.

## Overview

This personal portfolio website is designed to provide recruiters, technical interviewers, and potential freelance clients with a high-signal, interactive experience showcasing flagship projects and deep-dive technical case studies.

## Core Features

- **Hero & Intro:** Bold, experimental landing section.
- **About Section:** Qualifications, experience, and background.
- **Featured Projects & Case Studies:** In-depth technical write-ups covering problem statements, architecture, and results.
- **Tech Stack:** Skill matrix backed by real project implementation evidence.
- **Serverless AI Chat Assistant:** Context-stuffed serverless endpoint answering questions grounded in portfolio data.
- **Contact Section:** Direct contact channels.

## Getting Started

1. Clone the repository
2. Install dependencies:
   ```bash
   npm install
   ```
3. Copy `.env.example` to `.env.local` and add your required environment variables:
   ```bash
   cp .env.example .env.local
   ```
4. Run the development server:
   ```bash
   npm run dev
   ```
5. Open [http://localhost:3000](http://localhost:3000) in your browser.
